Cabinet IRs

Load a cabinet impulse response (.wav, 44.1/48/96 kHz) into one of the 16 user slots. The GX-10 does not play the file itself: Ailurus fits the unit's cabinet model to it, like BOSS TONE STUDIO does. A patch picks the slot with AIRD PREAMP → SP TYPE = USER 1..16. The unit cannot give an IR back, so the IR a slot holds now cannot be backed up; each one Ailurus loads is kept in your backup folder under IR.
