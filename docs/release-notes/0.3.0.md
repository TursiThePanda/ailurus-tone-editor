## Ailurus Tone Editor 0.3.0

- **Windows.** The app now runs on Windows 10/11 (x64): download
  `Ailurus-Tone-Editor-0.3.0-windows-setup.exe` and run it. It installs for your user only
  (no admin rights) and is not code-signed yet, so Windows SmartScreen warns the first time -
  click *More info → Run anyway*. BOSS TONE STUDIO for your unit must be installed, as on
  macOS. Updates arrive by themselves from now on, through [WinSparkle](https://winsparkle.org).
- **Choose where BOSS TONE STUDIO is.** If you installed it somewhere unusual, pick its
  folder in *Settings → BOSS TONE STUDIO*; the app finds the tables inside by itself and
  refuses a BOSS TONE STUDIO made for another unit.
- **Settings has tabs: General, BOSS TONE STUDIO and About.** About shows the version, the
  MCP address with the command to add it to Claude Code, the licence, the libraries the app
  is built on, and a *Check for updates* button - the menu items that only macOS had.
- Fixed: the "No unit connected" banner stayed on screen after the units connected (if the app was started before plugging them in).
- Fixed: switching patch from the app on the GX-10 was also logged as a switch made on the unit.
- Under the hood: a shared Roland BOSS TONE STUDIO base (rolandbts.py, RolandUnit, units/ registry), so other BOSS units can be added. Guide: docs/adding-a-unit.md. Read-only probe: tools/probe_unit.py.

On macOS, if you run 0.1.1 or later, this version arrives through the app's own updater.
