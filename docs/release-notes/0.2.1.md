## Ailurus Tone Editor 0.2.1

- **Unit menu.** The unit you edit is now picked from a drop-down menu in the top bar
  instead of a row of buttons, so it stays tidy as more units are supported. Units that
  are not plugged in are greyed out; hover one to see how to connect it.
- **Clearer messages.** With nothing plugged in the app says so in general terms; the
  advice specific to one unit (no USB hub for the GX-10, the KATANA3 Driver for the
  KATANA) appears only next to that unit.

If you run 0.1.1 or later, this version arrives through the app's own updater.
