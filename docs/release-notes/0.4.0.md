## Ailurus Tone Editor 0.4.0

- **Save and Save as.** Store what you hear in the current patch slot, or in another one under
  a new name (GX-10: U01-1..U66-3, KATANA Gen 3: A:CH1..B:CH4; never the GX-10's hidden slots
  or the KATANA's PANEL). Before every save the patch being replaced is backed up to
  `<backup folder>/Overwritten`, and *Settings → General* lists them with a *Put back* button.
  The AI may save too (`gx_save`) only after you turn on *Settings → General → "Let the AI
  save patches"*; it is off by default.
- **GX-10 cabinet IRs.** *Cabinet IRs* loads your own cabinet impulse response (.wav,
  44.1/48/96 kHz) into the GX-10's user IR slots USER 1..16 and renames them; a patch picks one
  with AIRD PREAMP → SP TYPE = USER n. The GX-10 does not play the file itself but a small
  cabinet model, so Ailurus fits that model to the IR with its own converter, as BOSS TONE
  STUDIO does with its own. The unit cannot give an IR back, so a slot that already holds one
  is replaced only after you confirm, and every IR Ailurus loads is kept in
  `<backup folder>/IR`. The AI can list the slots (`gx_list_irs`) but never loads an IR.
- **Linux.** `Ailurus-Tone-Editor-0.4.0-x86_64.AppImage` for x86_64: make it executable
  (`chmod +x`) and start it; the editor opens in your browser at `http://127.0.0.1:8710/`.
  Both units work with the kernel's own USB MIDI driver. BOSS TONE STUDIO comes from Roland:
  in *Settings → BOSS TONE STUDIO* accept Roland's licence and press *Download from Roland*,
  or give it the Windows installer you downloaded yourself. The AppImage does not update
  itself; it tells you when a newer release is out.
- Fixed: a second save right after another one on the GX-10 could fail while the unit was
  still storing the first.

On macOS and Windows this version arrives through the app's own updater.
