## Ailurus Tone Editor 0.1.1

- **Automatic updates.** The app checks for a new version once a day (and on demand with
  *Ailurus Tone Editor → Check for Updates…*). Updates are verified with an EdDSA
  signature before they are installed.
- This is the first version with the updater: if you run 0.1.0, install 0.1.1 by hand once.

The app is not notarized yet. On first launch macOS refuses to open it — go to
*System Settings → Privacy & Security* and click *Open Anyway*. Updates installed by the
app itself do not ask again.
