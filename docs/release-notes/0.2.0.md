## Ailurus Tone Editor 0.2.0

- **BOSS KATANA Gen 3 support.** Edit the amp live from the window or through MCP: every
  block with its GREEN / RED / YELLOW variation, amp type, FX types, CHAIN and the rest.
  Edits go to the current sound only; the amp's memories are never written.
  Switch patches (PANEL, A:CH1 .. B:CH4), see the signal in the order the amp plays it,
  and back up all 9 memories. Needs BOSS TONE STUDIO for KATANA Gen 3 installed (its
  tables are read at runtime) and Roland's *KATANA3 Driver*.
- **Several units at once.** With a GX-10 and a KATANA plugged in, a switcher at the top of
  the window picks the one you edit. MCP tools take an optional `device` argument, and the
  new `gx_select_device` changes the active unit. The history notes which unit changed.

If you run 0.1.1 or 0.1.2, this version arrives through the app's own updater.
